Understanding the Ethereum Classic backtest

These Ethereum Classic (ETC) charts compare the historical performance of the Clutch Swing strategy with buying and holding Ethereum Classic over the same analysis period. Each period starts with the same initial asset value.

The period return charts show cumulative returns in percent. The logarithmic charts show an asset index starting at 100: an index of 150 represents a 50% gain, while 80 represents a 20% loss. Blank areas indicate unavailable history.

The backtest assumes trades at the signal day's closing price and excludes transaction fees and slippage. Historical results do not guarantee future returns.
